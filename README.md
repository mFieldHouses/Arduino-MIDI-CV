# Arduino-MIDI-CV

Arduino-MIDI-CV is a small program written for use in my DIY synth made for a school project. It's built to support 3 concurrent voices; a fourth key press will overwrite the key that was pressed the longest time ago.

Intended future features:
 * Support for unison detune mode, where all 3 voices play the same note with a configurable amount of detune via a potentiometer
